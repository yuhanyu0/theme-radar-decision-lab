## Outcomes and causal bookkeeping

For each reader/order/world retain every observed-prefix native record, readiness, admission, shadow factual verdict and secondary route. Policies share that reader's exact prefix trajectory. FIRST_READY uses its own earliest native READY, or defers at B if none. All three policies require native admission for an issued factual answer. Missing admission and UNKNOWN/CONFLICT are distinct logged reasons for DEFER. Truth-based CORRECT/WRONG/DEFER is evaluated only after worker output. Strict worker request keys: query, offers, reader; each offer has body,family. This is interface isolation, not an OS security sandbox.

Primary reports: correct/wrong/defer, conditional error among issued answers, answer coverage, acquisition count, and matched-budget reader differences at K and B. Loss is wrong=1, defer=.25, correct=0 plus .02/query. Also report the prespecified defer grid {.1,.25,.5,1} x query-cost grid {0,.01,.02,.05,.1}. Units are abstract, not money.

Changing readers can change when READY occurs. Therefore do NOT call the FIRST_READY reader comparison a pure reading effect. Per world/order let tau_L and tau_S be each reader's own first-ready stopping time (budget fallback included). Decompose:

L(S,tau_S)-L(L,tau_L) = [L(S,tau_L)-L(L,tau_L)] + [L(S,tau_S)-L(S,tau_L)].

The first term holds acquisition count fixed; the second changes stopping time with the source-balanced reader held fixed. Report the reverse-reference decomposition too. These are path-specific accounting decompositions of observed synthetic counterfactuals, not unique natural causal effects. Report reader x stopping interaction: [L(S,B)-L(S,tau_S)] - [L(L,B)-L(L,tau_L)]. No winner, sign, statistical significance or effect magnitude is an integrity gate.
